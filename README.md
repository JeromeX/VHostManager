# VHostManager

**Webbasierte Verwaltung von virtuellen Hosts, IP-Sicherheit und Serveraktivitäten.**

> VHostManager ist eine Eigenentwicklung von Malte Speck.

VHostManager bündelt wichtige Verwaltungs- und Sicherheitsfunktionen in einer zentralen Weboberfläche. Ziel sind eine klare Übersicht, nachvollziehbare Ereignisse und die kontrollierte Verwaltung sicherheitsrelevanter Daten.

## Funktionen

- **Dashboard** – zentrale Übersicht über verfügbare Status- und Aktivitätsinformationen.
- **Besuchersicherheit** – sicherheitsbezogene Prüfung von Besucher- und IP-Aktivitäten.
- **IP-Verwaltung** – gespeicherte IP-Einträge prüfen und – abhängig von Version und Konfiguration – verwalten.
- **Gesperrte IPs** – gespeicherte Sperreinträge kontrollieren und pflegen.
